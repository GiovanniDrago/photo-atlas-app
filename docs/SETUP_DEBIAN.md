# Install dependencies on Debian / Linux

The Flutter tool needs a **x86_64** host. On this aarch64 device the tool cannot run: use GitHub
Actions or Codespaces instead ([WEB_TESTING.md](WEB_TESTING.md)), or run these steps on any x64
Debian/Ubuntu machine.

## 1. Flutter SDK

```bash
sudo apt update
sudo apt install -y curl git unzip xz-utils zip libglu1-mesa

cd ~
git clone https://github.com/flutter/flutter.git -b stable --depth 1 flutter
echo 'export PATH="$HOME/flutter/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
flutter --version
flutter doctor
```

The project pins Flutter `3.47.4` in the GitHub workflows; `flutter upgrade` or
`git checkout 3.47.4` inside `~/flutter` reproduces it.

## 2. Linux desktop dependencies

```bash
sudo apt install -y clang cmake ninja-build pkg-config libgtk-3-dev liblzma-dev
```

Then `flutter doctor` should report Linux desktop as available.

## 3. Android toolchain

```bash
sudo apt install -y openjdk-17-jdk

mkdir -p ~/Android/Sdk/cmdline-tools
cd /tmp
curl -O https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip commandlinetools-linux-*.zip -d ~/Android/Sdk/cmdline-tools
mv ~/Android/Sdk/cmdline-tools/cmdline-tools ~/Android/Sdk/cmdline-tools/latest

echo 'export ANDROID_HOME="$HOME/Android/Sdk"' >> ~/.bashrc
echo 'export PATH="$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$PATH"' >> ~/.bashrc
source ~/.bashrc

sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
flutter doctor --android-licenses
```

## 4. Get the project

```bash
git clone https://github.com/GiovanniDrago/photo-atlas-app.git
cd photo-atlas-app
flutter pub get
flutter gen-l10n
```

The `android/`, `linux/` and `web/` folders are generated by the `Scaffold platform folders`
workflow. If they are missing locally:

```bash
flutter create --platforms=android,linux,web --org dev.giovannidrago --project-name photoatlas .
bash scripts/configure-android.sh
```

## 5. Run

See [RUN.md](RUN.md).

## Resource notes

- `flutter pub get` and `flutter analyze` are light (a few hundred MB of RAM).
- Building Android needs Gradle and a JVM: plan for ~2 GB free RAM.
- Building web/linux is lighter but still needs ~1 GB free.
- On the aarch64 Debian-on-phone environment: only run `npm`-based tooling and the API there; leave
  Flutter builds to GitHub Actions.
